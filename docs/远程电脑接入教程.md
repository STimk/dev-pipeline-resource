# 远程电脑接入 dev-pipeline 完整教程

> 从零开始：新电脑配置 → 上传方案 → 拉取开发结果

---

## 第一章：首次配置

### 1.1 安装 Git

```bash
# Windows
# 下载: https://git-scm.com/download/win
# 一路下一步安装

# macOS
brew install git

# Linux (Ubuntu/Debian)
sudo apt install git -y

# Linux (CentOS/RHEL)
sudo yum install git -y
```

验证安装：

```bash
git --version
# 输出: git version 2.x.x
```

### 1.2 配置 Git 身份

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

> ⚠️ 这里的 name 和 email 会出现在 commit 记录中，建议用 GitHub 注册时的信息。

### 1.3 生成 SSH 密钥

为什么要 SSH？SSH 比密码更安全，配置一次后推送代码不用每次都输密码。

```bash
# Windows 在 Git Bash 里运行
# macOS/Linux 直接在终端运行

ssh-keygen -t ed25519 -C "你的邮箱@example.com"
```

按提示操作：

```
Generating public/private ed25519 key pair.
Enter file in which to save the key: ← 直接回车（默认路径）
Enter passphrase:                   ← 直接回车（不设密码）
Enter same passphrase again:        ← 直接回车
```

成功后会显示：

```
Your identification has been saved in ~/.ssh/id_ed25519
Your public key has been saved in ~/.ssh/id_ed25519.pub
```

### 1.4 查看公钥并添加到 GitHub

```bash
cat ~/.ssh/id_ed25519.pub
```

会输出类似这样的内容：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... 你的邮箱@example.com
```

**复制整段输出**，然后：

```
1. 浏览器打开 https://github.com/settings/keys
2. 点击 "New SSH key"
3. Title 填: "我的新电脑"
4. Key 粘贴上面复制的内容
5. 点击 "Add SSH key"
```

### 1.5 同样的步骤添加 Gitee（可选）

```
1. 浏览器打开 https://gitee.com/profile/sshkeys
2. 点击 "添加 SSH 公钥"
3. 标题填: "我的新电脑"
4. 公钥粘贴上面 cat 的内容
5. 确定
```

### 1.6 测试连接

```bash
# 测试 GitHub
ssh -T git@github.com
# 成功输出: Hi STimk! You've successfully authenticated...

# 测试 Gitee
ssh -T git@gitee.com
# 成功输出: Hello Diver! You've successfully authenticated...
```

## 第二章：拉取仓库

### 2.1 克隆仓库

```bash
# 选一个目录放项目，比如 D:\Projects\
cd D:\Projects\

# 克隆（第一次）
git clone git@github.com:STimk/dev-pipeline.git

# 或者用 HTTPS（如果 SSH 不熟）
git clone https://github.com/STimk/dev-pipeline.git

# 进入目录
cd dev-pipeline
```

### 2.2 查看目录结构

```bash
ls -la
# 应该看到:
#   待开发/     ← 放新的开发方案
#   开发中/     ← 正在开发的项目（远程看是空的）
#   开发完/     ← 已完成的项目
#   .dev-logs/ ← 开发日志
#   README.md  ← 完整工作流说明
```

## 第三章：上传开发方案

### 3.1 创建方案目录

```bash
# 命名规则: YYYY-MM-DD-项目名称

# Linux/macOS
mkdir -p "待开发/$(date +%Y-%m-%d)-项目名称"

# Windows (cmd)
mkdir "待开发\%date:~0,4%-%date:~5,2%-%date:~8,2%-项目名称"

# Windows (PowerShell)
mkdir "待开发/$(Get-Date -Format 'yyyy-MM-dd')-项目名称"
```

### 3.2 写方案文件

创建 `开发方案.md`，内容模板：

```markdown
# 开发方案：项目名称

## 项目概述
一句话描述这个项目。

## 功能需求
1. 功能一
2. 功能二

## 技术栈
- Python 3.12
- 依赖库
```

```bash
# Linux/macOS
vim "待开发/2026-07-26-项目名称/开发方案.md"

# Windows 用记事本或其他编辑器
notepad "待开发\2026-07-26-项目名称\开发方案.md"
```

### 3.3 提交并推送

```bash
# 添加新文件到 Git
git add 待开发/

# 提交
git commit -m "feat: 新项目方案 - 项目名称"

# 推送到远程
git push origin master
```

如果推送失败：

```bash
# 先拉取最新代码，再推送
git pull --rebase origin master
git push origin master
```

### 3.4 验证上传成功

```bash
# 浏览器打开
# https://github.com/STimk/dev-pipeline/tree/master/待开发

# 或者命令行查看
git ls-tree HEAD 待开发/
```

## 第五章：常见问题

### Q1: `git push` 提示权限 denied

```
原因: SSH 密钥没配好
解决:
  1. 检查密钥: cat ~/.ssh/id_ed25519.pub
  2. 确认已添加到 GitHub: https://github.com/settings/keys
  3. 测试连接: ssh -T git@github.com
```

### Q2: `git push` 提示 rejected

```
原因: 远程有更新，本地落后了
解决:
  git pull --rebase origin master
  git push origin master
```

### Q3: 没有 git 怎么办？

浏览器直接上传：

```
1. 打开 https://github.com/STimk/dev-pipeline
2. 点击 Add file → Upload files
3. 在本地建好 待开发/2026-07-26-项目名/开发方案.md
4. 把文件夹拖到上传区域
5. Commit changes → Commit directly to master branch
```

### Q4: 想下载某个已完成项目的代码

```bash
# 方式一：完整仓库（推荐）
git clone git@github.com:STimk/dev-pipeline.git
# 然后取 开发完/ 下的项目

# 方式二：只下载单个文件夹（用 svn 方式）
# 安装 svn 后:
svn export https://github.com/STimk/dev-pipeline/trunk/开发完/2026-07-26-项目名称
```

## 附录：SSH 密钥管理

### 查看已有密钥

```bash
ls -la ~/.ssh/
# 如果看到 id_ed25519 和 id_ed25519.pub，说明已有密钥
```

### 多台电脑共用一个密钥

不安全，不推荐。每台电脑应该生成独立的密钥。

### 切换电脑后更新密钥

如果换了新电脑，旧电脑的密钥可以删除：

```
GitHub: https://github.com/settings/keys → 删除旧电脑的 key
Gitee:  https://gitee.com/profile/sshkeys → 删除旧电脑的 key
```

### Windows 特别注意

```
1. 安装 Git 时选 "Use Git from Git Bash only"
2. 所有 git 命令在 Git Bash 里运行
3. 路径用正斜杠 / 而不是反斜杠 \
4. 密钥生成也在 Git Bash 里运行
```
