## 版本升级流程

当需要更新版本时，我自动执行：

```bash
# 1. 存档当前活跃版
cp skill/SKILL.md archive/dev-collab-ultimate-v5.X.Y.md

# 2. 修改 skill/SKILL.md 为新版本
vim skill/SKILL.md
# version: X.Y.Z

# 3. 双推
git add -A
git commit -m "chore: vX.Y.Z 变更说明"
git push origin master
```

## 版本回退方法

### 方式一：回退 skill 内容

```bash
# 查看所有历史版本
ls archive/

# 回退到指定版本
cp archive/dev-collab-ultimate-v4.4.0.md skill/SKILL.md

# 加载使用
hermes -s dev-collab-ultimate-v5
```

### 方式二：回退到某个 skill 完整版本

```bash
# 直接从 git 历史拉取
git log --oneline                        # 查看提交历史
git checkout <commit-hash> -- skill/     # 恢复某个版本的 skill
```

### 方式三：使用冻结版

```bash
# v3.0.0 初代版
hermes -s dev-collab-ultimate

# v4.4.0 冻结版
hermes -s dev-collab-ultimate-v4

# v5.0.0 活跃版（当前）
hermes -s dev-collab-ultimate-v5
```
